安装 Zotero 插件

在文献库中查看、筛选和保存期刊指标。

Journal Scout for Zotero

下载后，在 Zotero 中打开「工具 → 插件」，通过齿轮菜单从文件安装。

安装清单声明支持 Zotero 7–10；已在 10.0.8 实测，7–9 尚未逐版测试。Zotero 6 不支持；v0.1.0 可升级至 v0.1.1，获取独立指标筛选、影响因子数值比较、新版侧栏及显示设置。
下载 Zotero 插件XPI · v0.1.1

安装步骤

  1. 下载插件点击上方按钮保存 Zotero XPI 文件，无需解压。
  2. 打开插件管理在 Zotero 顶部选择「工具 → 插件」。
  3. 从文件安装点击右上角齿轮，选择「Install Plugin From File…」，选中下载的 XPI；如有提示，重启 Zotero。
  4. 查看期刊或会议信息选择期刊论文或会议论文，查看列表中的 Journal Scout 列；如未显示，可在表头的列菜单中启用。

功能与数据说明

查看与筛选：在文献表格的 Journal Scout 列查看期刊和会议指标，选中文献后也可在右侧查看详情。高级搜索的字段菜单中，选择「Journal Scout → 影响因子、中科院分区、JCR 分区、Top 或 CCF 等级」等独立指标，无需选择「标签」。

影响因子数值筛选：选择「Journal Scout → 影响因子」，中间可选「等于」「不等于」「大于」「小于」，右侧输入数字，例如 10.5。小数按完整数值比较；要筛选 10 到 20 之间的文献，可添加「大于 10」和「小于 20」两条条件并匹配全部，也能与分区组合后保存搜索。没有影响因子的文献不会被当作 0。

兼容原生标签筛选：以下配图展示另一个独立入口：已有 Journal Scout 原生标签仍可在左侧标签栏或高级搜索的「标签」条件中筛选。它用于文本匹配；数值范围请使用上面的 Journal Scout 指标字段。

保存与同步：已确认的结果自动写入条目的 Extra（附加信息）区块及 Zotero 标签，并保留区块以外的原有内容和用户标签。条目的更改可能随 Zotero 同步，也可能出现在部分导出文件中；本地缓存可供同一期刊复用。

处理文库：筛选读取已归档到本地的指标，执行搜索不会重新请求网站。日常查看会逐步补全当前显示或选中的期刊和会议论文；需要完整筛选整个文库时，请先在主窗口选择文库，再进入「设置 → Journal Scout」，点击「补全文库期刊指标」，覆盖该文库的全部分类。设置页会显示进度，运行时提供「取消」按钮；取消后保留已归档结果，关闭设置后重新打开也能继续查看进度。插件优先复用已有归档和本地缓存，无法确认刊物或会议、只读或正在编辑的条目可能被跳过，未匹配或跳过的条目可稍后重试。使用独立指标搜索时需保持 Journal Scout 插件启用。

查询数据：插件使用条目的期刊名或 ISSN 查询 ScanSci 期刊服务，不发送论文全文或附件。会议论文按会议名称匹配 CCF 目录；插件内置 ABS / AJG、UTD24、FMS 和 ABDC 商科名单。未收录或无法确认的条目不会显示对应等级。

显示设置：侧栏按指标分项列出，标签保留所选配色、字号和圆角。点击侧栏的「显示设置」，或进入 Zotero「设置 → Journal Scout」，可选择「列表列与侧边栏」或「仅侧边栏」，并逐项勾选需要显示的标签。仅侧边栏模式会隐藏 Journal Scout 列；选择立即生效并保存在本机，完整指标仍归档到 Extra 和原生标签。「标签样式」中可调整配色、字号、圆角和间距。配色选框采用彩色圆角样式，文字间距与字号、圆角选项保持一致。

数据更新：已确认的期刊和会议记录会在本地复用；网站发布数据更新后，插件错峰优先更新当前查看的文献。

插件更新：发现更高的插件版本时，右侧面板会提示前往下载；下载后通过插件管理器从文件安装。已经安装 v0.1.0 的用户，可下载 v0.1.1 安装包，通过插件管理器从文件安装升级。

插件由 ScanSci 提供，Zotero 标识用于指示适用的软件。
