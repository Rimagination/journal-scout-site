从官方商店安装免费 · 自动更新

安装步骤

  1. 点击「获取」确认发布者是 ScanSci，点击「获取」并添加。
  2. 固定图标在工具栏的扩展菜单中固定 Journal Scout。
  3. 刷新论文页面刷新支持的学术页面；点击插件图标可调整设置。
下载离线安装包ZIP · v0.1.11

安装步骤

  1. 下载并解压下载上方 ZIP，解压后保留文件夹。
  2. 打开 Edge 扩展页在地址栏输入 edge://extensions，打开右上角的「开发人员模式」。
  3. 加载插件点击「加载解压缩的扩展」，选择解压后的文件夹（里面有 manifest.json）。

手动更新：新版本发布后下载新版 ZIP，解压并覆盖原文件，再到 edge://extensions 点击「重新加载」。

请选择一种方式，避免重复安装。

下载离线安装包ZIP · v0.1.11

安装步骤

  1. 下载并解压下载上方 ZIP，解压后保留文件夹。
  2. 打开 Chrome 扩展页在地址栏输入 chrome://extensions，打开右上角的「开发者模式」。
  3. 加载插件点击「加载已解压的扩展程序」，选择解压后的文件夹（里面有 manifest.json）。
  4. 开始使用在工具栏扩展菜单中固定 Journal Scout，再刷新已打开的论文页面。

手动更新：新版本发布后下载新版 ZIP，解压并覆盖原文件，再到 chrome://extensions 点击「重新加载」。

推荐使用官方商店版，避免重复安装。

从 Firefox 官方商店安装免费 · 自动更新

安装步骤

  1. 添加插件在 Firefox 扩展商店点击「添加到 Firefox」并确认。
  2. 开始使用在工具栏固定 Journal Scout，再刷新论文页面。
下载 Firefox 测试包XPI · v0.1.11
  1. 下载测试包下载上面的 XPI 文件，无需解压。
  2. 打开调试页面在 Firefox 地址栏输入 about:debugging#/runtime/this-firefox 并回车。
  3. 临时载入点击「临时载入附加组件」，选择刚才下载的 XPI 文件，然后刷新论文页面。

Firefox 测试包官网测试包尚未签名，只能临时载入；退出 Firefox 后需要重新载入。

下载 Mac 临时测试包ZIP · v0.1.11

Mac Safari 临时安装

  1. 开启开发者功能在 Safari「设置 → 高级」中启用网页开发者功能。
  2. 允许临时扩展在 Safari「设置 → 开发者」中允许未签名扩展。
  3. 加载测试包选择「添加临时扩展」，打开下载的 ZIP 或解压后的文件夹，再刷新论文页面。

Safari 测试限制该包尚未在 Safari 真机验证，仅供支持临时扩展的 Mac Safari 测试；退出 Safari 或 24 小时后需重新加载。iPhone 和 iPad 不能直接安装此 ZIP。
