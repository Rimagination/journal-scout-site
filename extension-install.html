Mac Safari 临时安装

  1. 开启开发者功能在 Safari「设置 → 高级」中启用网页开发者功能。
  2. 允许临时扩展在 Safari「设置 → 开发者」中允许未签名扩展。
  3. 加载测试包选择「添加临时扩展」，打开下载的 ZIP 或解压后的文件夹，再刷新论文页面。

Safari 测试限制该包尚未在 Safari 真机验证，仅供支持临时扩展的 Mac Safari 测试；退出 Safari 或 24 小时后需重新加载。iPhone 和 iPad 不能直接安装此 ZIP。

安装 Zotero 插件

在文献库中查看、筛选和保存期刊指标。

Journal Scout for Zotero

下载后，在 Zotero 中打开「工具 → 插件」，通过齿轮菜单从文件安装。

安装清单声明支持 Zotero 7–10；已在 10.0.8 实测，7–9 尚未逐版测试。Zotero 6 不支持；插件有新版本时会提示下载安装。
下载 Zotero 插件XPI · v0.1.0

安装步骤

  1. 下载插件点击上方按钮保存 Zotero XPI 文件，无需解压。
  2. 打开插件管理在 Zotero 顶部选择「工具 → 插件」。
  3. 从文件安装点击右上角齿轮，选择「Install Plugin From File…」，选中下载的 XPI；如有提示，重启 Zotero。
  4. 查看期刊信息选择期刊论文，查看列表中的 Journal Scout 列；如未显示，可在表头的列菜单中启用。

功能与数据说明

查看与筛选：在文献表格的 Journal Scout 列查看影响因子、分区等已匹配指标，选中文献后也可在右侧查看详情。指标写入 Zotero 原生标签，可在左侧标签栏筛选，或在高级搜索中使用「标签」条件。影响因子标签是文本，暂不支持按数值范围筛选。

保存与同步：已确认的结果自动写入条目的 Extra（附加信息）区块及 Zotero 标签，并保留区块以外的原有内容和用户标签。条目的更改可能随 Zotero 同步，也可能出现在部分导出文件中；本地缓存可供同一期刊复用。

处理文库：默认逐步处理当前显示或选中的期刊论文。要处理整个文库，请选择文库后点击「工具 → Journal Scout：为当前文库建立筛选标签」；可通过停止菜单中断。插件优先复用已有归档和本地缓存，无法确认期刊、只读或正在编辑的条目可能被跳过，未匹配或跳过的条目可稍后重试。

查询数据：插件使用条目的期刊名或 ISSN 查询 ScanSci 期刊服务，不发送论文全文或附件。插件内置 ABS / AJG、UTD24、FMS 和 ABDC 商科名单；未收录或无法确认的期刊不会显示对应等级。

数据更新与样式：已确认的期刊记录会在本地复用；网站发布数据更新后，插件错峰优先更新当前查看的文献。右侧「标签样式」可选择配色、字号和圆角，设置保存在本机。

插件更新：发现更高的插件版本时，右侧面板会提示前往下载；下载后通过插件管理器从文件安装。已经安装过旧的 v0.1.0 的用户，可重新下载本页安装包并手动安装一次。

插件由 ScanSci 提供，Zotero 标识用于指示适用的软件。
