INSTALLATION GUIDE

选择你的浏览器

当前版本尚未上架浏览器商店，请按下面的步骤安装。

EMicrosoft Edge桌面版 · Edge 116 或更高⌄
下载插件安装包ZIP · v0.1.5
  1. 下载并解压解压上面的 ZIP 文件，保留解压后的文件夹。
  2. 打开扩展页面在 Edge 地址栏输入 edge://extensions 并回车，打开并保持「开发人员模式」。
  3. 加载插件点击「加载解压缩的扩展」，选择解压后的文件夹（包含 manifest.json）。
  4. 开始使用在工具栏扩展菜单中固定「ScanSci 文献助手」，再刷新已打开的论文页面。
CGoogle Chrome桌面版 · Chrome 116 或更高⌄
下载插件安装包ZIP · v0.1.5
  1. 下载并解压解压上面的 ZIP 文件，保留解压后的文件夹。
  2. 打开扩展页面在 Chrome 地址栏输入 chrome://extensions 并回车，打开并保持「开发者模式」。
  3. 加载插件点击「加载已解压的扩展程序」，选择解压后的文件夹（包含 manifest.json）。
  4. 开始使用在工具栏扩展菜单中固定「ScanSci 文献助手」，再刷新已打开的论文页面。
FFirefox桌面版 · Firefox 140 或更高 · 临时安装⌄
下载 Firefox 测试包XPI · v0.1.5
  1. 下载测试包下载上面的 XPI 文件，无需解压。
  2. 打开调试页面在 Firefox 地址栏输入 about:debugging#/runtime/this-firefox 并回车。
  3. 临时载入点击「临时载入附加组件」，选择刚才下载的 XPI 文件，然后刷新论文页面。

关于 Firefox 安装当前测试包尚未签名，只能临时载入；退出 Firefox 后需要重新载入。长期安装及自托管自动更新需要 Mozilla 签名。

已经安装过？

下载新版 ZIP，将文件覆盖到原插件文件夹，在扩展页面点击「重新加载」，再刷新论文网页。保留原目录以继续使用已有设置和收藏。当前解压版手动更新程序文件；期刊数据继续从 ScanSci 在线获取。
